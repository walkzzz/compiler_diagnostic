## 项目简介

本项目旨在增强仓颉编译器诊断系统的结构化能力，实现：

1. **诊断字段结构化**：Parser/Sema 诊断包含错误码、位置信息、建议修复
2. **JSON 诊断输出**：符合 LSP 规范的标准化 JSON 格式
3. **性能零劣化**：新增诊断逻辑不引入性能退化
4. **回归稳定性**：错误码体系稳定，不破坏现有诊断
