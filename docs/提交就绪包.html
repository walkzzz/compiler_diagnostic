二、作品简介
compiler-diagnostic 面向仓颉编译器开发者，提供结构化的编译器诊断输出能力，覆盖 Parser 高频语法错误与 Sema 类型/泛型/重载/可见性诊断，并产出面向 IDE 与 AI 的结构化 JSON 诊断字段（兼容 LSP 规范），配套诊断样例库、贡献指南与回归测试基线。核心能力：稳定错误码（E0001–E0005、E1001–E1004）、准确定位（span）、可执行修复建议（fix）、复杂语义错误的根因（rootCause）与候选符号/类型（Candidate{name,kind}）及关联位置（related）。
