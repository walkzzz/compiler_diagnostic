# 独立测试包拆分与按子包运行指南

> 配套改动：`cjpm.toml` 的 `test-dir` 由 `"src"` 改为 `"test"`；`src/{ut,hlt,llt}` 通过 `git mv` 整体迁至 `test/{ut,hlt,llt}`。生产代码（`src/` 下除测试外的包）保持不变。

## 1. 目标与结构

将测试源码从生产模块 `src/` 中物理剥离，形成**独立的测试包**，并按测试层次拆分为三个子包，支持**每次只运行一个子包**。

```
compiler-diagnostic/
├── src/                      # 生产代码（不再含任何 *_test.cj）
│   ├── diagnostics/          # 诊断核心（ErrorCode / ErrorMeta / fromCode ...）
│   ├── output/  cli/  common/  semantic_trace/  benchmark/  ...
├── test/                     # 独立测试包（test-dir = "test"）
│   ├── ut/                   # 单元测试：编译器诊断库内部单元
│   ├── hlt/                  # 高层测试：诊断覆盖、字段完整性、桥接
│   └── llt/                  # 端到端测试：JSON/LSP 输出、解析诊断（EXEC 集成验证）
└── tools/run_tests.{sh,cmd}  # 按子包运行的运行器
```

每个子包对应一个 cjpm 包名（`compiler_diagnostic.ut` / `hlt` / `llt`），包声明未变，仅目录位置变更。

## 2. 按子包运行

cjpm 原生支持"只测试指定包"：`cjpm test [pkg-path ...]`（help 原文：*If you specify some package paths, it will only test those specified packages*）。

| 意图 | 命令 |
|------|------|
| 仅单元测试 | `cjpm test ut` |
| 仅高层测试 | `cjpm test hlt` |
| 仅端到端测试 | `cjpm test llt` |
| 全量 | `cjpm test` |

> 包路径 `ut`/`hlt`/`llt` 是相对于 `test-dir` 的包路径，与 `ci_test/ciTest.py` 既有约定一致（`cjpm test ut` / `hlt` / `llt`）。子包内还可叠加 `--filter <TestClass>` 精确筛选用例（见各 `test_*.cj` 文件头部的 `// EXEC` 注释）。

### 运行器（推荐）

```bash
# Git Bash / Linux / macOS
./tools/run_tests.sh ut        # 只跑 ut
./tools/run_tests.sh hlt       # 只跑 hlt
./tools/run_tests.sh llt       # 只跑 llt
./tools/run_tests.sh all       # 依次 ut -> hlt -> llt（默认）

# Windows CMD
tools\run_tests.cmd ut
```

运行器已内置 vendored SDK 的 PATH 锁定（与 `cjpm.toml` 相对路径一致），无需在本机硬编码绝对路径。若需覆盖，设置 `CANGJIE_HOME` 环境变量即可。

## 3. 环境约定（重要）

- **SDK 锁定仓库内 vendored 1.1.3**（用户硬性要求）：`cangjie-sdk-1.1.3/cangjie` + `cangjie-stdx-1.1.3.1`。运行器默认指向它。
- **Git Bash 下运行**：PowerShell 非 TTY 时 `cjpm test` 完全静默、不生成报告；Git Bash 正常输出 `Summary: TOTAL / PASSED / FAILED`。
- **首跑抖动**：`cjpm build` / `cjpm test` 首跑偶发 `SIGSEGV(139)` 或静默 `127`，**清 target 后重试即稳过**（记忆记载）。本沙箱因全量链接期内存受限，无法在此完成整仓编译；请在真实 1.1.3 环境复核。
