# 仓颉编程语言错误码体系（扩展版）

> 基于原有 E00–E90 十大类体系，补充缺失的编译阶段与工具链类别，并为每类展开子错误码明细。
> 编号规则：`E<大类><-子序号>`，如 `E00-001`。子序号从 001 起，预留扩展空间。

---

## 一、错误码大类总表（扩展后）

| 前缀 | 类别 | 阶段 | 说明 |
|------|------|------|------|
| E00 | Lexer 词法 | 编译前 | 字符流 → Token 阶段的词法错误 |
| E01 | Parser 语法 | 解析 | Token → AST 阶段的语法错误 |
| E02 | Macro 宏 | 解析 | 宏展开、过程宏、编译期计算错误 |
| E10 | Sema 语义 | 语义 | 语义分析阶段的通用语义错误 |
| E20 | Type 类型 | 语义 | 类型检查、类型推导、泛型约束错误 |
| E30 | Resolution 名字解析 | 语义 | 标识符解析、导入、作用域、重载决议错误 |
| E40 | Codegen 代码生成 | 后端 | 中间代码生成、目标代码生成错误 |
| E41 | Optimizer 优化器 | 后端 | IR 优化、内联、死代码消除等优化阶段错误 |
| E42 | Linker 链接器 | 后端 | 符号链接、库链接、段合并错误 |
| E43 | Assembler 汇编器 | 后端 | 汇编指令生成、目标文件格式错误 |
| E50 | Runtime 运行时 | 运行 | 程序运行期异常、崩溃、资源错误 |
| E60 | Lsp / IDE | 工具链 | 语言服务器、IDE 集成、代码补全/诊断错误 |
| E70 | Build / Package 构建与包管理 | 工具链 | cjpm 构建、依赖解析、cjpm.toml 配置错误 |
| E71 | Test 测试框架 | 工具链 | 单元测试、断言、覆盖率、测试运行器错误 |
| E72 | Doc 文档生成 | 工具链 | 文档注释解析、API 文档生成错误 |
| E73 | Fmt 格式化 | 工具链 | 代码格式化、风格检查错误 |
| E74 | Debugger 调试器 | 工具链 | 调试信息生成、断点、调试协议错误 |
| E75 | Profiler 性能分析 | 工具链 | 性能采样、热点分析、PGO 错误 |
| E90 | System 系统 | 运行 | 操作系统、文件IO、内存、环境等系统级错误 |

## 三、错误级别约定

| 级别 | 标识 | 说明 | 退出码影响 |
|------|------|------|-----------|
| ERROR | `error[EXX-XXX]` | 必须修复，阻止编译/运行 | 非零退出 |
| WARNING | `warning[EXX-XXX]` | 建议修复，不阻止编译 | 不影响退出码（`-Werror` 时转为 ERROR） |
| NOTE | `note:` | 附加说明，附属于错误/警告 | 无独立退出码 |
| HELP | `help:` | 修复建议，附属于错误/警告 | 无独立退出码 |
| ICE | `internal error[EXX-XXX]` | 编译器内部错误，应上报 bug | 非零退出 + 崩溃报告 |

## 四、编号空间规划

| 区间 | 用途 |
|------|------|
| E00–E09 | 前端：词法、语法、宏 |
| E10–E39 | 中端：语义、类型、名字解析 |
| E40–E49 | 后端：代码生成、优化、链接、汇编 |
| E50–E59 | 运行时 |
| E60–E69 | LSP / IDE |
| E70–E79 | 工具链：构建、测试、文档、格式化、调试、性能 |
| E80–E89 | 预留（未来扩展：安全审计、形式化验证等） |
| E90–E99 | 系统级 |

每个大类下子码 `001–999`，其中：
- `001–099`：通用错误
- `100–199`：平台/目标相关错误
- `200–899`：具体场景错误
- `900–999`：内部/预留
