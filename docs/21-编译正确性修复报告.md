## 一、背景与核心结论

前序的“代码质量修复 / 覆盖率提升”工作（docs/16、docs/20）是在**工具链不可用、未经验证编译**的情况下完成的。经对照权威仓颉 1.1.3 知识库逐项核验后发现：**项目源码与测试在真实 API 下无法编译**——所谓 97% 行覆盖率、93% 分支覆盖率是在“不会编译通过”的代码上产生的，不能作为质量证据。

本轮“夯实基础”的核心目标，是把**所有与真实仓颉 API 不符、会导致编译失败的问题**逐类定位并修复，使项目在 `cjpm build` / `cjpm test` 下具备可编译、可运行的基础。

> ⚠️ 本环境无 `cjc`/`cjpm` 工具链，无法实际执行编译。所有修复均通过**权威知识库（cangjie-coding）逐 API 核验** + **全项目静态扫描**完成，并给出可复核的验证证据。请在你的环境中执行 `cjpm build` 与 `cjpm test` 做最终确认。

## 二、仓颉 1.1.3 关键 API 事实（本轮核验依据）

| 误区（旧写法） | 真实 API | 说明 |
|------|------|------|
| `String[i]` 返回 `Char`/`Rune` | 返回 `Byte`（UTF-8 字节） | 不能把 `String[i]` 当字符遍历或与字符串字面量比较 |
| 遍历字符用索引 | `String.toRuneArray(): Array<Rune>` | 字符级处理走 Rune 数组 |
| `Rune` 字面量 `'a'` | `'a'` 是 `String`，字符字面量是 `r'a'` | `UInt32(r)` 取码点，`Rune(n)` 回转 |
| `List` 是具体类型，`[]` 是 List | `List<T>` 是**接口**，`ArrayList<T>` 才是具体类；`[]` 是 **Array** 字面量 | `let x: List<T> = []` 编译错误，须用 `ArrayList<T>()`；`ArrayList<T>([...])` 合法（`Array<T> <: Collection<T>`）|
| `Map` 是具体类型，`Map()` 可用 | `Map<K,V>` 是**接口**，`HashMap<K,V>` 才是具体类 | `Map()` 实例化接口非法，须用 `HashMap()` |
| `std.time()` 取时间 | **不存在**；用 `MonoTime.now()`（`import std.time.*`）+ `Duration` | `MonoTime - MonoTime → Duration`；`Duration.toMilliseconds(): Int64` |
| 数值互转 `.toInt64()`/`.toFloat64()` | 用**构造器语法** `Int64(n)` / `Float64(n)` | Cangjie 无此类方法 |
| `String.join(arr, ", ")` 位置参数 | 命名参数 `String.join(arr, delimiter!: String)` | `delimiter` 为必填命名参数 |
| `HashMap` 用 `containsKey` / `get` 返回裸值 | `contains(key): Bool`；`get(key): ?V`（返回 `Option`） | 索引赋值 `m[k] = v` 合法 |
| `main` 返回 `Unit` | 约定 `main(args: Array<String>): Int64` | 入口函数返回 `Int64` 并 `return 0` |

**已确认可用的真实 API**（用于本报告的修复与验证）：
- `ArrayList<T>` 构造：`init()`、`init(elements: Collection<T>)`（故 `ArrayList<T>([...])` 合法）。
- `extend<T> Array<T> <: Collection<T>`（故 `Array<String>` 可作 `Collection<String>` 传入 `ArrayList` 构造）。
- `List<T>` / `Map<K,V>` 为接口；`ArrayList<T> <: List<T>`、`HashMap<K,V>` 为具体实现。

## 四、详细修复记录

### A. `escapeJson` 重写为 Rune 级处理（src/output/JSONOutput.cj）
旧实现把 `String[i]` 当 `Char` 使用（`c < "\u0020"`、`c.unicodeValue()`、`result.replace(c, escaped)`），全部非法。新实现：
- 先处理 `\\ " \n \r \t` 的 `replace`；
- 对剩余字符走 `for (r in result.toRuneArray())`，以 `UInt32(r)` 取码点，码点 `< 32u32` 时输出 `\u` + 两位十六进制；
- 新增 `hexDigit(n: UInt32): String` 辅助（0–15 → `'0'..'F'`）。

### B. 计时改用 `MonoTime`（src/benchmark/PerfBenchmark.cj）
- 新增 `import std.time.*`；
- `std.time()` 全部替换为 `MonoTime.now()`，`(MonoTime.now() - start).toMilliseconds()` 得 `Int64`，再 `Float64(...)` 转浮点；
- `compareWithBaseline` 增加除零保护（`baseline.elapsedMs > 0` 才除，否则取 1.0）。

### C. `String.join` 命名参数（src/output/TextOutput.cj）
`String.join(arr, ", ")` → `String.join(arr, delimiter: ", ")`。

### D/E. `List`/`Map` 与 `candidates:` 的 Array→List 修复（全项目）
核心规则：`List`/`Map` 为接口，`[]` 是 Array 字面量。所有“应以 List 接收、却传 Array”的位置统一改为 `ArrayList`/`HashMap` 构造。

**生产代码**：
- `src/main.cj`：`generateSampleDiagnostics` 内 2 处 `candidates: ["...", "..."]` → `candidates: ArrayList<String>([...])`；`let result: List<...> = ArrayList<...>()`。
- `src/diagnostics/DiagnosticCollector.cj`：`messages`/`newList` 用 `ArrayList<...>()`；`Map()` → `HashMap<...>()`。
- `src/diagnostics/Diagnostics.cj`：所有 `related`/`this.related` 的 `[]` → `ArrayList<RelatedInfo>()`。
- `src/diagnostics/DiagnosticBuilder.cj`：`related` 字段 `ArrayList<RelatedInfo>()`。
- `src/output/JSONOutput.cj`、`TextOutput.cj`：`output(diagnostics: List<...>)` 形参保持接口类型（调用方传 `ArrayList`）。
- `examples/demo/main.cj`：2 处 `candidates: [...]` → `ArrayList<String>([...])`（该文件已使用裸 `ArrayList` 且无需 `import std`，印证 `std` 可自动/由 harness 引入）。

### F. `main` 返回类型（src/main.cj、examples/demo/main.cj）
`main(args: Array<String>): Int64` 并 `return 0`（demo 同改）。

### G. 删除未使用导入（warning=0 门禁）
`src/main.cj` 删除未使用的 `ErrorCode`、`DiagnosticCollector` 等导入；`examples/demo/main.cj` 删除未使用的 `ErrorCode` 导入。

### H. 删除死代码桩
`src/diagnostics/ParserDiagnostic.cj`、`SemaDiagnostic.cj` 中空的 `collect(messages: List<DiagnosticMessage>): Unit { }` 桩方法已删除（从未被调用）。

### I. 新增 `BenchmarkResult.summary()`（src/benchmark/BenchmarkReport.cj）
demo 调用 `result.summary()`，但 `summary()` 原仅存在于 `BenchmarkReport`。为 `BenchmarkResult` 增加对称的 `summary(): String`（输出 `耗时=…ms, 峰值内存=…MB`），使 demo 可编译，且为合理 API 补充。

## 六、遗留事项与建议

1. **必须在真实环境复核编译**：本环境无 `cjc`/`cjpm`，请执行：
   ```
   cjpm build
   python ci_test/ciTest.py all --coverage
   ```
   并确认 `ci_test/ci_test.cfg` 的 `warning = 0` 门禁通过。
