#### 2.3 诊断字段演示（60 秒）

**重点展示字段**：
| 字段 | 说明 | 示例 |
|------|------|------|
| `code` | 错误码 | "E0001" |
| `severity` | 严重级别 | "error" |
| `message` | 诊断消息 | "未终止的字符串字面量" |
| `span` | 源码位置 | {start: {line, column}, end: {line, column}} |
| `fix` | 修复建议 | {description, replacement} |
| `related` | 关联位置 | [{span, message}] |
| `candidates` | 候选符号（结构化） | [{"name":"var1","kind":"variable"}, {"name":"var2","kind":"variable"}] |

**脚本参考**：
> "每条诊断消息包含完整的 LSP 兼容字段。以 E0001 为例，除了基本的错误码和消息，还包含源码位置信息（span）、修复建议（fix）等。对于未定义标识符的错误，还可以提供候选符号列表，帮助开发者快速定位问题。"

## 🎬 录制建议

### 工具推荐
| 工具 | 平台 | 特点 |
|------|------|------|
| **OBS Studio** | Windows/Mac/Linux | 免费开源，功能强大 |
| **ScreenRec** | Windows | 简单易用，自动录制 |
| **PowerToys** | Windows | 内置录屏功能 |
| **Mac 录屏** | Mac | 快捷键 Cmd+Shift+5 |

### 录制设置
1. **分辨率**：1920x1080（1080p）
2. **帧率**：30fps
3. **音频**：使用耳机麦克风，避免回音
4. **光标**：开启光标高亮，便于观众跟随

### 录制技巧
1. **分段录制**：按章节录制，减少出错重来
2. **预留缓冲**：每段开始前停顿 2 秒，便于剪辑
3. **屏幕清理**：录制前关闭无关窗口和通知
4. **语速适中**：不要太快，给观众理解时间
5. **重复关键操作**：重要命令执行两遍，便于观众看清
