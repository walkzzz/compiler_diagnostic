### 🟠 Major（重要级）- 2 个

#### M001: BenchmarkResult 字段无验证
- **文件**: `src/benchmark/BenchmarkReport.cj` 第 5-13 行
- **问题**: `elapsedMs` 和 `peakMemoryMB` 为 Float64，无正数验证
- **风险**: 负值或 NaN 会导致 `compareWithBaseline` 逻辑异常
- **修复建议**:
```cangjie
public init(elapsedMs: Float64, peakMemoryMB: Float64) {
    assert(elapsedMs >= 0, "elapsedMs must be non-negative")
    assert(peakMemoryMB >= 0, "peakMemoryMB must be non-negative")
    this.elapsedMs = elapsedMs
    this.peakMemoryMB = peakMemoryMB
}
```

#### M002: JSON 字符串转义不完整
- **文件**: `src/output/JSONOutput.cj` 第 111-119 行
- **问题**: `escapeJson` 方法仅处理了 `\\`, `\"`, `\n`, `\r`, `\t`，但未处理其他控制字符（U+0000-U+001F）
- **风险**: 包含控制字符的 message 会导致输出 JSON 格式错误
- **修复建议**:
```cangjie
private func escapeJson(s: String): String {
    var result = s
    result = result.replace("\\", "\\\\")
    result = result.replace("\"", "\\\"")
    result = result.replace("\n", "\\n")
    result = result.replace("\r", "\\r")
    result = result.replace("\t", "\\t")
    // 处理其他控制字符
    for (i in 0..<result.size) {
        let c = result[i]
        if (c < "\u0020") {
            result = result.replace(c, "\\u" + c.unicodeEscape())
        }
    }
    return result
}
```

### 🟡 Minor（建议级）- 6 个

#### Mi001: getSeverity 函数是死代码
- **文件**: `src/diagnostics/Diagnostics.cj` 第 196-198 行
- **问题**: `getSeverity` 函数硬编码返回 `"error"`，且未被任何代码调用
- **建议**: 删除该函数，或在 ErrorCode 枚举中添加 severity 字段

#### Mi002: DiagnosticMessage 构造函数过度重载
- **文件**: `src/diagnostics/Diagnostics.cj` 第 142-193 行
- **问题**: `DiagnosticMessage` 有 5 个构造函数重载，调用方难以选择合适参数
- **建议**: 统一使用 `DiagnosticBuilder` 模式，删除 `DiagnosticMessage` 的 public 构造函数

#### Mi003: DiagnosticBuilder.setFix 参数类型不一致
- **文件**: `src/diagnostics/DiagnosticBuilder.cj` 第 25-28 行
- **问题**: `setFix` 接受 `FixSuggestion`（非 Option），但内部包装为 `Some(fix)`，调用方需理解此隐式转换
- **建议**: 直接接受 `Option<FixSuggestion>`，或由调用方决定是否包装

#### Mi004: SourceLoc 构造函数冗余
- **文件**: `src/diagnostics/Diagnostics.cj` 第 10-26 行
- **问题**: 3 个构造函数重载，可通过默认参数简化
- **建议**: 仓颉不支持默认参数，当前设计合理，但可考虑使用 Builder 模式

#### Mi005: 注释密度不足
- **文件**: 多处
- **问题**: 部分公共接口缺少注释说明
- **建议**: 为公共方法添加文档注释

#### Mi006: 变量命名风格不统一
- **文件**: `src/main.cj` 第 64 行
- **问题**: `main` 函数参数名为 `args`，但内部使用 `parseArgs(args)`
- **建议**: 统一使用 `arguments` 或 `args`
