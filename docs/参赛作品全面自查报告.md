## 3. 竞品 / 合规风险核查（硬编码路径与用户名）

**扫描结论**：源码、`cjpm.toml`、`cjpm.lock`、`README.md`、`examples/*.cj`、CI 脚本中**未发现**本机绝对路径或用户名硬编码（上一轮 `Administrator` 硬编码已修复，全仓无 `Administrator` 源码残留）。

**唯一真实隐患（P0 合规）**：`ci_test/ci_test.cfg` 仍含他人开发机绝对路径：
```
ci_test/ci_test.cfg:12   3rd_party_root = /home/lyq/workspace
ci_test/ci_test.cfg:26   home = /home/lyq/cangjie_env
```
- 这是另一台 Linux 开发机（用户名 `lyq`）的路径，**非本机**、**非赛事评委环境**；
- 若评委用 `python ci_test/ciTest.py` 运行，可能因 `home` 指向不存在路径而失败；
- 即便主门禁走 `cjpm test`（不读该路径）也能过，但该硬编码仍属「个人路径泄露 + 不可复现」风险，与 commit `7d077ac`「去除绝对路径硬编码」的整改主题相悖（该 commit 仅修了 stdx 路径，未修 ci_test.cfg 的 lyq 路径）。
- **修复建议（2 行）**：将 `home` 置空或改为相对/占位（评委经 `CANGJIE_HOME` 提供 SDK），`3rd_party_root` 改为 `./` 或仓库相对路径。
