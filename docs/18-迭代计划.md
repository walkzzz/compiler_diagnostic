#### 1.1 真实性能基准数据
**当前问题**：`PerfBenchmark` 为 stub 实现，返回默认值
**目标**：提供真实的性能测量数据

**实现方案**：
```cangjie
// PerfBenchmark.cj 增强
public func runBenchmark(inputFiles: List<String>): BenchmarkResult {
    // 1. 测量编译时间
    let start = currentTime()
    // 模拟编译诊断消息的生产
    let diagnostics = generateSampleDiagnostics()
    let elapsedMs = currentTime() - start
    
    // 2. 测量内存峰值
    let peakMemoryMB = estimateMemoryUsage(diagnostics)
    
    return BenchmarkResult(elapsedMs, peakMemoryMB)
}
```

**验收标准**：
- [ ] 执行时间 < 100ms（1000 条诊断）
- [ ] 内存占用 < 50MB
- [ ] 与 baseline 对比 ≤ 1.05x

#### 1.3 增强示例代码
**当前问题**：`examples/demo/main.cj` 过于简单
**目标**：展示完整功能流程

**增强方案**：
```cangjie
// examples/demo/main.cj
package examples.demo

import compiler_diagnostic.diagnostics.*
import compiler_diagnostic.output.*
import compiler_diagnostic.benchmark.*

func main(): Unit {
    // 1. 生成诊断消息
    let loc1 = SourceLoc(line: 10, column: 5, file: "demo.cj")
    let loc2 = SourceLoc(line: 10, column: 20, file: "demo.cj")
    let span1 = Span(start: loc1, end: loc2)
    
    let parserDiag = ParserDiagnostic()
    let diag1 = parserDiag.reportUnterminatedString(span: span1)
    
    // 2. 文本输出
    let textOutput = TextOutput()
    println("=== 文本输出 ===")
    println(textOutput.output([diag1]))
    
    // 3. JSON 输出
    let jsonOutput = JSONDiagnosticOutput()
    println("\n=== JSON 输出 ===")
    println(jsonOutput.output([diag1]))
    
    // 4. 性能基准
    let benchmark = PerfBenchmark()
    let result = benchmark.runBenchmark(["demo.cj"])
    println("\n=== 性能基准 ===")
    println(result.summary())
}
```
