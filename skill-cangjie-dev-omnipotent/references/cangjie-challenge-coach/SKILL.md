## 核心能力

### 0. 选题决策支持（Phase 0）
- 分析 **9 技术课题（K1–K9）+ 73 三方库候选（L 组）+ 自选命题** 的优劣势（见 `仓颉生态创新开发挑战赛清单.md`）
- 根据团队技术背景（源语言 Rust/Java/Go/C/C++/Python/JS/Algorithm）推荐命题与建议包名（`xxx4cj` / `-cj` / `-ffi`）
- 结合竞争热度（`11`/`12`/`14`）判断拥挤 vs 稀疏方向
- 输出《选题决策报告》

### 1. 组队与报名指导（Phase 0）
- 组队要求：**1–4 人，1 作品**；成员确认后原则上不改
- 报名页：`https://competitions.atomgit.com/competition/2090379383571447809/intro`
- 推荐命题无报名上限、可多队同题；自选命题**无需认领/锁题/前置审核**，但须自行查重（与 Cangjie-TPC / cj-awesome 不构成实质性重复），提交时附项目提案

### 2. 开发进度管理（Phase 1）
- 里程碑：S1 基础实现 → S4 提交准备
- **9 技术课题验收指标（K1–K9）是硬性门槛**，任何一条不达标在自查报告中标红 ❌ 阻断
- 推荐 AI 工具（M 组，见 §10）辅助开发；AI 生成可复用 Skill/Agent/MCP/工作流可申报加分

### 3. 提交前自查（Phase 2）
- 执行本角色卡目录下 `references/checklist.md` 的 A–O 组逐项检查
- 判断阻断项/警告项/建议项
- 输出《参赛作品自查报告》；门禁结论：✅ 可提交 / ❌ 需返工

### 4. 提交执行指导（Phase 3）
- 提交清单：仓库同步到 cj-codelabs / 演示视频链接 / 统一作品提交模板(9部分) / 邮件
- 三方库上架：STS 1.1.3 环境 → `cjpm bundle -V` → `cjpm publish -V`；409=版本已存在需升 version；`cangjie-repo.toml` 加 `.gitignore`
  - **`cjpm bundle` 会以 MANDATORY 级跑 cjlint**：`&&`/`||` 右操作数含函数调用会触发 `G.EXP.03` 直接阻断发布（仓库级 `cjlint` 仅当 warning）。上架前务必先 `cjpm bundle -V` 预检，命中即把右操作数函数调用提为局部变量。
  - **`cjpm publish` 报 `401 authentication failed` = 注册中心 token 为空**：配置在 `~/.cjpm/cangjie-repo.toml` 的 `[repository.home].token`（默认空）。该 token 与 git 凭据**无关**（`cjpm` 无 `login` 子命令）；到 `https://pkg.cangjie-lang.cn` 登录生成 Personal Access Token（`QXCT_` 前缀）填进该字段即可。
  - 完整发布/工具链陷阱见本目录 `references/toolchain-gotchas.md`。

### 5. 初赛后准备（Phase 4）
- 入围门槛：初赛基础分 **≥60** 且「代码质量与可靠性」**≥18** 且材料完整可查
- 前 **30 名** 进决赛（2026-10-16 公示）
- 未入围可争取参与奖（前 40 名，按初赛成绩排序）

### 6. 决赛路演准备（Phase 5）
- 决赛路演基础 100 分（见 §评分标准）
- 迭代检查：功能/性能/Benchmark/测试覆盖≥90%/文档/差异说明
- 路演结构 10–15 分钟：项目介绍→核心演示→技术方案→Q&A

### 7. 赛后跟进（Phase 6）

## 评分标准（来自 `01-赛事规则与评审标准.md`，权威）

### 初赛基础评分（100 分）
| 维度 | 分值 |
|---|---|
| 代码质量与可靠性 | 30 |
| 创新性 | 20 |
| 实用性 | 20 |
| 文档完善度 | 15 |
| 实现完成度 | 10 |
| 社区影响（Star/Fork，截至 10-07 23:59:59） | 5 |

### 加分项
- **仓颉 AI 生态贡献加分**：最高 **10 分**（初赛、决赛分别评审，不沿用）。类型：工具/Skill/Agent/MCP 工具/工作流/提示模板/语料/示例；评分=生态相关2+实际可用3+可复用2+完整性2+可验证1。**普通 AI 辅助生成代码/测试/文档不单独加分**。须提交仓库或 PR 链接 + 安装运行复用说明 + 验证材料。
- **HCIA-Cangjie Developer 认证**：初赛 **+3 分**（同一团队多人持证不重复；仅用于入围排序，不计入最终综合成绩）。

### 决赛路演基础评分（100 分）
核心功能演示 30 / 技术方案与实现说明 20 / 实用价值与生态贡献 15 / 迭代成果 15 / 答辩表现 15 / 路演完整性 5。

### 成绩计算
- 初赛总分（含加分）= 初赛基础 + AI 贡献 + HCIA，最高 **113**
- 计入最终综合的初赛分 = 初赛基础 + AI 贡献，最高 **110**
- 决赛总分 = 决赛路演基础 + AI 贡献，最高 **110**
- **最终综合成绩 = 计入初赛分 ×30% + 决赛分 ×70%**（满分 110）
- 入围门槛：基础 ≥60 且 代码质量 ≥18
- 同分：依次比决赛总分→核心功能演示→技术方案→迭代成果→答辩→AI 贡献→实用价值→路演完整性
